NOUR SERHAN — INTERACTIVE PORTFOLIO (preview, not yet published)

index.html   THE PORTFOLIO. One self-contained file: open it in Chrome or Safari
             (double-click). One slide per project; click any slide or "View project"
             to open a full-screen gallery of every image and video.
             Keys: ↑ ↓ between projects · ← → inside a project · Esc to close.
             Project images and videos stream from your Wix media library, so stay online.

TO SHARE WITH A CLIENT (free, about 1 minute):
  go to https://app.netlify.com/drop and drag this folder (or just index.html) onto the page.
  You get a public link you can send. Or upload index.html to any web host.

profile.html  8-page PDF profile (open in Chrome/Safari > Print > Save as PDF,
              margins None, background graphics on). Needs the a/ folder next to it.
CHECKLIST.md  Internal: every Wix page → slide, counts, and items that couldn't be imported.
src/          Editable source. Edit src/data.js, then: python3 src/build_deck.py index.html
